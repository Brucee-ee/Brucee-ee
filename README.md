## Projects

**SEVERN EYE**
Passive RF monitoring station over the Bristol Channel, fusing ADS-B and AIS traffic into one anomaly detection pipeline. My main project right now. Hardware station still in progress.

**SKYPOINTER**
ADS-B tracker with live RTL-SDR decoding and a servo gimbal that points at the nearest aircraft in real time. Isolation Forest flagging anomalies across 11,168 tracked aircraft.

**ML Intrusion Detection System**
XGBoost classifier trained on CICIDS 2017, 4.2M real network flows, 27 attack types. 0.9999 accuracy, 0.9998 F1. Streamlit dashboard with live prediction.

**Malware Classifier**
LightGBM binary classifier trained on EMBER 2018, 800k Windows PE file samples. Static analysis only, no sandbox needed. 0.9965 ROC-AUC.

**Phishing URL Detector**
Random Forest classifier on the UCI Phishing Dataset. Works off URL structure alone, no need to actually fetch the page.

**Threat Intel: CVE Severity Classifier**
TF-IDF + Logistic Regression model that predicts CVE severity from the description text. Trained on NVD data, useful for triaging new vulnerabilities early.

**Recalled**
AI flashcard app built with React and the Anthropic API. Six quiz modes, deployed at recalled.site.
